# astrbot_plugin_sysinfo

一条 `/sys` 命令看服务器的 CPU、内存、磁盘、网络、运行时长。

## 命令

```
/sys          完整信息
/系统信息      中文别名
```

## 输出示例

```
CPU   12.4%  (8 核)
内存   6.2G / 20.0G  (31%)
磁盘   102G / 296G  (35%)
网络   ↑ 1.2 MB/s  ↓ 8.4 MB/s
运行   12 天 3 小时
```

## 权限

**仅白名单 QQ 可用**（默认只有主人）。这是有意的——服务器负载信息不适合给群里所有人看。

白名单在配置里改：

```json
{ "allow_qqs": ["你的QQ号"] }
}
```

## 依赖

无额外依赖，读 `/proc` 和 `psutil`（若已安装则用它拿更准确的数据）。
